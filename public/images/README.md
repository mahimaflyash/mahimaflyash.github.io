# Photos

Put your photos here, then set the path in `src/app/data/site-data.ts`.

- Home banner     -> `public/images/banner/`    e.g. image: 'images/banner/fly-ash-bricks.jpg'
                     (wide photos, about 1920 x 800 px — edit BANNER_SLIDES)
- Product photos  -> `public/images/products/`  e.g. image: 'images/products/fly-ash-bricks.jpg'
- Gallery photos  -> `public/images/gallery/`   e.g. image: 'images/gallery/plant-1.jpg'

Tips: use .jpg or .webp, landscape (4:3), and keep each file under ~300 KB
(resize to about 1200px wide) so the site loads fast on mobile.
